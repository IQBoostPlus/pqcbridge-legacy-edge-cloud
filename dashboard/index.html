How to read this dashboard Definitions, assumptions & limits

Coverage measures migration

PQC coverage = PQC connection segments ÷ all in-scope segments, including unknowns. The percentage is rounded to one decimal place. Zero records means unavailable coverage. This is a migration indicator, not a security guarantee.

Exposure is not a detected attack

Harvest-now-decrypt-later (HNDL) exposure describes traffic that could be collected now and decrypted later under the stated key-establishment and confidentiality assumptions. This dashboard does not detect HNDL attacks. Expected classical fallback alone is not proof of a downgrade; suspected events are explicitly labelled synthetic scenarios.

Time and overall status

Records older than 24 hours relative to the selected clock are stale. Historical mode evaluates the fixed snapshot at its own time; current-time mode assesses its age now. Priority: suspected downgrade → red; empty, unknown, stale or future-dated evidence → unknown; remaining fallback → amber; otherwise → green for reported segment migration only. These prototype rules await team/PO review.

Segments and model boundaries

Device-to-gateway and gateway-to-cloud are separate segments. ML-KEM on one segment does not establish end-to-end PQC protection. The course's synthetic classical-key-exchange scenario is distinct from the existing prototype's preconfigured symmetric-key device path. Local JSON data is validated as a whole; invalid snapshots are rejected rather than silently excluding records.
